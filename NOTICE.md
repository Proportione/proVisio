## Licence unification (MIT → Apache-2.0)

The private working copy of this repository was initially released under MIT License (in a prior local-only iteration dated 2026-05-05). With effect from version `v0.1.0` (planned release date: post-CAPSI 2026 acceptance decision), all files in this repository are **relicensed under Apache License, Version 2.0**.

The unification was decided to:

1. **Align with the public companion repository** at `github.com/Proportione/proVisio` (originally `github.com/Proportione/visio`), which has been Apache-2.0 from the start.
2. **Provide an explicit patent grant** to downstream users, which MIT does not.
3. **Simplify replication and contribution** by having a single licence across the public reference implementation and this architecture-and-methodology release.

The MIT-licensed working copy is preserved in `LICENSE.mit-backup-20260622` for traceability.
